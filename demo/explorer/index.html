File explorer

An OS-style file manager over vfs-sync. It starts on a new tab: browse this origin's OPFS on the left — folders holding a .vfs store open straight into tabs — or open a MemFS or a real folder from your disk on the right. Every open root is a tab; inside one, a tree on the left and a details pane with size, mime, checksum and how the same path stands on every other root. The footer picks a sync target and runs it.

Demo Coverage GitHub npm

Try it: create a folder on the new tab, open it as a root (the first one is seeded with a few files), open a MemFS next to it, and edit notes.md on both without syncing in between. Then set the footer's target to All roots and hit Sync — the newer edit wins and the other one is preserved as a (conflict …) copy. Switching roots keeps the open file selected, so the details pane shows the same path — size, checksum and all — as another filesystem sees it.

The explorer is a standalone app in explorer/; this page contributes a heading and one line of script: 

import { mountExplorer } from '../../explorer/src/index';

mountExplorer('#explorer');

It carries its own scoped styles and reads nothing from the host page, so npm run explorer:build also gives you a static build to serve on its own and drop into an <iframe>.
